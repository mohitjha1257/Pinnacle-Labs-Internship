# ☕ Pinnacle Labs – Java Development Internship

A collection of Java console-based projects developed as part of my **Java Development Internship at Pinnacle Labs**.

This repository contains two beginner-friendly Java applications that demonstrate fundamental programming concepts, problem-solving skills, and practical implementation of Java.

## 📌 Projects Included

### 1. Currency Converter 💱

A menu-driven Java application that converts amounts between six different currencies using predefined exchange rates.

**Supported Currencies:**
- USD – US Dollar
- EUR – Euro
- GBP – British Pound
- INR – Indian Rupee
- JPY – Japanese Yen
- CAD – Canadian Dollar

**Features:**
- Interactive currency selection menu.
- Converts between supported currencies using USD as the base currency.
- Accepts user-defined amounts.
- Validates menu selections and numerical inputs.
- Prevents negative amounts.
- Displays conversion results up to two decimal places.
- Allows users to perform multiple conversions.

**File:** `CurrencyConverter.java`

### 2. Tic-Tac-Toe Game 🎮

A two-player, command-line Tic-Tac-Toe game developed using Java.

**Features:**
- Classic 3 × 3 game board.
- Two-player gameplay (X and O).
- Interactive row and column selection.
- Validates user moves.
- Prevents players from selecting occupied cells.
- Automatically detects winning combinations.
- Identifies draw conditions.
- Displays the updated game board after every valid move.

**File:** `ticTacToe.java`

### Prerequisites

- Java Development Kit (JDK) installed.
- Visual Studio Code or any Java-supported IDE.
